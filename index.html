Computer vision · Live demo ● Try it on your phone

CarScan AI

Photograph any car and a vision model names the make, model and year from the badge, grille and lamp signature - then checks it against a dealer inventory of 177 vehicles. The interesting part is what it refuses to do: identification and catalog matching are deliberately separate steps, so an unstocked model returns nothing rather than the nearest lookalike.

~7sfrom photo to matching stock, on one serverless function

Claude Vision · n8n · Serverless · Prompt engineering · Redis rate limiting · No app, no framework

Network observability · Local AI ● Built in one afternoon

dnswatch

Every device you own talks to the internet constantly and there is no screen that shows you to whom. So I put the phone book in the house: a resolver that logs every request, names the company behind it using a model running on my own GPU, and can simply not answer. The interesting part is what it admits: asked to identify domains, one model invented a company for six out of six names I had made up, so the interface marks every claim as verified fact or model guess, and leaves a fifth of them openly unrecognised.

154companies contacted in one afternoon · 1 in 5 requests now blocked

Python stdlib only · qwen2.5 on local GPU · DNS-over-HTTPS · WireGuard · Deep CNAME inspection · No dependencies
